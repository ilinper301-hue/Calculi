# Calculi: cálculo mental

App web para aprender **trucos de cálculo mental** y practicarlos jugando (1.º de Primaria). Cada truco sigue tres pasos: **Aprender** (tutorial animado) → **Practicar** (paso a paso) → **Reto y juego**.

Forma parte del mismo ecosistema que **Lectori** (lectura) y **Barri** (problemas con barras).

## Qué incluye
- 16 estrategias de 1.º en tres trimestres: del marco del 10 a las decenas completas.
- Modelos visuales: marco del 10 y del 20, puntos, dedos, parte-todo, recta numérica y decenas.
- Dificultad que se adapta, repaso del día que mezcla lo aprendido y actividad «¿Qué truco usarías?».
- Perfiles, Modo Docente (todo abierto, sin guardar), zona de adultos con semáforo de dominio y copia de seguridad.
- Se instala como app y funciona sin conexión. Tema claro y oscuro.

## Desarrollo
- Código en `src/`; `python3 tools/build.py` genera `index.html`.
- Pruebas: `node tests/test_motor.js`.
- Ver `CLAUDE.md` y `ESTADO.md`.
